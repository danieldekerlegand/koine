# koine/decisions — Architecture Decision Records

The ADRs that record *why* the fabric is shaped the way it is. An ADR captures one decision — its
context, the choice, the alternatives rejected, and the consequences — and is **agnostic**: it
binds roles (producer / consumer / authority / host / provider), never a named product.

| [`ADR-0007-self-describing-participant.md`](ADR-0007-self-describing-participant.md) | **A participant is self-describing; its communication config lives at the edge.** Everything a peer needs in order to talk to a participant — its namespace + minting authority (KINP §3.4), its KCB capability manifest as the AgentCard extension (KCB §2), its egress policy (KGP §7.2), and its bridge/predicate mappings — is published by that participant, from its own repo and its own served endpoints. No central hub or shared config store holds it; the discovery registry returns an **address** to a self-description, never the self-description. Extends ADR-0001 (route-by-lookup, not route-by-proxy) to configuration, and is what lets a downstream participant hold its own config instead of depending on a shared store. | Accepted (2026-08-02) |
| [`ADR-0008-fabric-producer-adapter.md`](ADR-0008-fabric-producer-adapter.md) | **An application joins the fabric as a producer through a thin adapter.** The adapter only *translates* — local records into KGP claims over registry relations, KMI asset references + lineage, a KFT dataset **by reference**, and a KCB manifest on the AgentCard — while every generic data-plane bridge (admission, license/egress filtering, merge, the ADR-0006 projections, OTIO round-trips) is built once in the runtime commons. Per-application bridge and projection modules are **superseded**, generalizing KMI §4.3's withdrawal of `skill_export_*` and KINP §4.1's query-time merge view. Closes the grounding-relation fork: a mention→canonical assertion is a source-local-id **`same_as`** (or `based_on` across the §4.3 firewall), merged at query time — **no `mentions` relation is coined**. | Accepted (2026-08-06) |
| [`ADR-0009-capability-versioning-deprecation.md`](ADR-0009-capability-versioning-deprecation.md) | **Semver states intent, a content digest establishes identity.** Decides how a provider evolves a capability's schema without breaking subscribers — resolving KCB §7.2's fork (semver on capability names *vs* content-addressed schemas) by layering both: a capability is `(name, semver version)`, every port carries an algorithm-prefixed `schema_id` that makes a forgotten bump detectable, and a breaking change is published as a **successor alongside the predecessor**, never edited in place — the rule the immutable relation signature and content-addressed ids are already instances of. Fixes the subscriber-compatibility table, binds grants to a **major** so a breaking change cannot widen an issued token, keeps `cost` outside the digest but never silent (spend ceilings fail closed), and resolves KFT §11.5's inheritance: a finetuned model's pinned `kft_version` is an **archival** pin — retirement ends the obligation to emit or accept, never the ability to read. Fixes the **deprecation half** too: a deprecation names its own end — an explicit removal version declared at the moment of deprecation, measured in the retiring surface's own versions rather than wall-clock dates, at least one minor out, dual-served until then, and moveable later but never earlier — the policy under which KMI §4.4's dateless `edl+json` window and KCB §2.2's standalone manifest location each get a concrete removal version. | Accepted (2026-08-13) |
| [`ADR-0010-kmi-lineage-bridge-not-vocabulary.md`](ADR-0010-kmi-lineage-bridge-not-vocabulary.md) | **KMI is a bridge between C2PA and MovieLabs OMC, not a third lineage vocabulary.** A prior-art sweep found KMI §3's asset-lineage graph was claiming unoccupied ground that is in fact occupied twice over — by **C2PA**'s cryptographically signed ingredient chain (`parentOf` / `componentOf` / `inputTo`, hash-based hard bindings, a conformance program listing 159 certified products as observed 2026-08-13) and by **MovieLabs OMC v2.8**'s richer derivation vocabulary (Revision / Variant / Derivation / Representation / Alternative). Weighs shipping the third vocabulary unmapped, adopting C2PA wholesale, and adopting OMC wholesale — rejecting the first as the losing move that also leaves every implementer to invent the mapping privately, the second because it would make a certificate mandatory for internal bookkeeping and has no place for a probabilistic `perceptual_match`, the third because a production-domain ontology demands relation choices a generic transcode pipeline cannot make. Narrows KMI's claim to the analysis→knowledge bridge and world-scoping. | Accepted (2026-08-13) |
| [`ADR-0011-governance-deliberation-voting-dissent-non-goal.md`](ADR-0011-governance-deliberation-voting-dissent-non-goal.md) | **Deliberation, voting and dissent preservation are non-goals.** A published governance taxonomy (Kang & Diponegoro, arXiv:2606.31498, 30 June 2026) names six dimensions; koine is measured *Partial* on membership, human escalation and audit/replay, and **Absent** on the other three. This record decides those three rather than leaving them to read as debt. The reasons are measured, not asserted: **every gate koine specifies is unilateral** — KGP §7 license/egress, KCB §5 grant and ceiling, KFT §4 admission and §8.1 refusal are each one participant deciding for itself, with refusal always available — so there is nothing to aggregate preferences over; **no cross-organizational edge requires a joint decision**, and the one vote observed anywhere in the known implementations is intra-organizational answer selection, which is not preference aggregation in the taxonomy's sense; and a **prior-art sweep dated 2026-08-18 came back empty** — FIPA's standard set (© 2002) covers task allocation and bilateral negotiation, ERC-5805 is *Stagnant* and covers vote weight rather than deciding, dissent preservation has no standards-body work at all, and none of the three agent BoFs at IETF 126 (Vienna, 18–24 July 2026) scopes collective decision-making. With nothing to profile, specifying would be **inventing**, which `78-kft-adopt-by-reference` forbids. Dissent is shown to be *dependent* on voting (there is no decision output to preserve a minority position in) while the property it protects — a minority view surviving — is already KGP's. States a checkable **re-open trigger** (T1 a binding joint decision across two KINP §3.4 minting authorities · T2 a standard to profile · T3 a koine gate ceasing to be unilateral) and explicitly **does not** dismiss G1 / G5 / G6, which stay measured *Partial* with findings GOV-1…GOV-3 open. | Accepted (2026-08-18) |

Local, offline-first minting remains independent of authority reachability; federation adds authority-boundary selection plus reconciliation, registry peering, and replication handling rather than redefining the existing single-holder contracts. Names the pressure-test hazards: cross-authority `same_as`, peered discovery, and CAS replication on reference. | Accepted (2026-08-23) |
| [`ADR-0013-autonomy-posture-boundary-clause.md`](ADR-0013-autonomy-posture-boundary-clause.md) | **Autonomy posture is a contract clause, in the boundary half only.** Decides the parked question raised 2026-08-19 by a consumer-side safety-mode vocabulary, and decides it against the two edges that actually cross an ownership boundary (`../ECOSYSTEM.md` §3, informative) rather than in the abstract. **Yes to the concern:** a posture governing a cross-owner dispatch is interchange, which resolves the boundary half of the **G5 human escalation** carve-out [ADR-0011](ADR-0011-governance-deliberation-voting-dissent-non-goal.md) §4 deliberately left undecided. **No to the ladder:** postures are named by the **classes of effect they permit unattended**, never by a console's rung names, which become a declared *projection* onto that vocabulary in the ADR-0010 relationship. The decision rests on two dated measurements — a posture gates spend **and irreversibility**, and while KCB §5 grants/ceilings express spend and enforce it unilaterally, **no clause, field or enum anywhere in the fabric names irreversibility**, so a caller's posture is not weak at the boundary but *inapplicable*; and the only mechanisms that bind across an ownership line are the callee's unilateral gates plus the credential the caller narrows, so an advisory mode flag buys nothing (the nearest prior art is a set of hints whose own specification says not to rely on them). Mints exactly one operand — a port's **effect class**, absent reading *unknown* and never *harmless* — plus a posture operand on existing verbs, and one conflict rule: a posture is **monotone-restrictive**, so the effective posture is the **intersection**, *the restriction always wins*, no peer's declaration can widen any gate, and refusal stays available to both — which is also what preserves ADR-0011's unilateral-gate premise so its trigger **T3 does not fire**. The **floor** — the part a caller may assume of a callee it has never met — is that no posture relaxes KGP §7 license/egress, KCB §5 grant/ceiling or KFT §4/§8.1, an unadmitted effect is a **refusal** never a silent proceed or substitution, and an undeclared class is not admitted. No new plane, verb, artifact kind or authority role, and it MUST be expressible by an implementation with **no console at all**. The prematurity objection is answered rather than dismissed: nothing in the decision derives from the console (its four rungs appear once, rejected), and the **second-independent-implementation** condition is retained as a gate on **ratification** alongside the pressure-test scenario. States three checkable **withdrawal triggers** (W1 the effect class is not declarable by its declarant · W2 a standards-body specification appears, answered by profile-by-reference · W3 the second implementation cannot project onto the vocabulary), and explicitly leaves the approval mechanism, the human authority, intra-organizational supervision, and **GOV-2**'s decision record outside its scope. No spec version moved **in this record**; the clause it authorizes was written the same day as normative **KCB §4.3** (0.4.8, patch), pressure-tested by [`../scenarios/kcb-cross-owner-posture.md`](../scenarios/kcb-cross-owner-posture.md) — see this record's **Amendment log**, which notes that every verdict survived and one hole none of them covered (**AP-5**, a pairwise posture evaporating on a delegated leg) is closed by §4.3e's chain rule. | Accepted (2026-08-26) |

## Why the numbering skips ADR-0002 – ADR-0004

This repo holds **contract shape**, not deployment instance data. The records above are the
agnostic, contract-level stances (*koine specifies, the runtime commons implements*), so they stay.
Three records in koine's original numbering — **ADR-0002 / 0003 / 0004** (bridge reconciliation, the
contract-layer consolidation, and the Erlang provider-router) — are **deployment-history** decisions
tied to a specific operator's rollout. They were moved to that operator's **private integration
repo**, which continues koine's ADR numbering.

So a citation of `ADR-0002`, `ADR-0003`, or `ADR-0004` refers to a document that is deliberately
**not in this repo** — there is no missing file here to link, by design (see
[`../CLAUDE.md`](../CLAUDE.md)). Those three numbers stay reserved; new agnostic ADRs take the next
free number **at or above 0005**, so nothing collides with the downstream sequence. New
ADRs added here must clear the same bar: if a decision would read the same for any other ecosystem,
it belongs here; if it names a particular deployment's topology or adoption program, it is instance
data and belongs downstream.
