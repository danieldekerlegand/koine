## Codebase Patterns

- **koine has almost no code.** 140 tracked files: 65 json, 57 md, 7 tsv, 5 mjs, 2 sh.
  No `package.json`, no dependencies, no runtime (ADR-0001: "koine specifies, agora
  implements"). The entire executable surface is `scripts/check-*.mjs` (5 guards) plus
  `.chief/verify.sh` + `.chief/verify-test.sh`. A "dead code" sweep here is a sweep of
  seven files.
- **`.chief/verify.sh` is the one gate, and it is path-selective.** Run it as
  `.chief/verify.sh --run <changed paths...>` — a bare run diffs `main...HEAD`, so it
  reports "no changed files" on an uncommitted working tree. `--plan` prints the
  selected gates without running them. A path matching NO rule selects the **umbrella**
  (every gate, including the self-test).
- **`check-doc-integrity.mjs`'s slugify is NOT GitHub's.** It collapses `\s+` to a
  SINGLE hyphen, so `## Class A — dead: removal candidates` anchors as
  `#class-a-dead-removal-candidates`, not GitHub's `#class-a--dead-removal-candidates`.
  Writing the GitHub form fails the gate. Match the guard.
- **`MD_LINK` fires inside backticks.** Writing `` `[text](path)` `` in prose is parsed
  as a link and reported as "no such file — path". Split the form when writing about it.
- **`tasks/chief/completed/` is history and must not be rewritten** — both doc guards
  skip it as a citer, and reference counts that include it measure the past.

### Learnings for future iterations

- **Re-run every search AT REMOVAL TIME, not just at inventory time.** They cost seconds. An
  inventory is a claim about a moment, and the tree moves between the two. Writing the search
  into the commit message is what forced the re-run here — do that.
- **"Is it used?" is the wrong question. "Is it used, OR ABOUT TO BE?" is the right one.**
  Grep the *active tasklists* (`tasks/chief/*.json`, excluding `completed/`) as part of every
  deadness search. A-4's searches were re-run under the corrected question and came back
  clean; A-3's did not survive it.
- **`check-doc-integrity.mjs`'s `slugify` strips `_` as well as backticks and `*`** (line 67,
  `.replace(/`|\*|_/g, '')`). So `### A-1 — `EXCEPT_DIRS`, and …` anchors as
  `#a-1-exceptdirs-…`, NOT `#a-1-except_dirs-…`. Cost one red gate. Add this to the slugify
  note already in Codebase Patterns.
- **The `guard-doc-links` ratchet is a free before/after test of any change to that script.**
  It checks out `$CHIEF_BASE_BRANCH` into a temp worktree and runs the **pre-change** script
  there. `0 dead vs 0 on main` after a removal is a real measurement, not a tautology.
- **US-3 inherits a strong seed.** The undecidability register should lead with the A-3
  retraction as the concrete case of what a static search over this tree cannot see, alongside
  C-1's eight registry rows (cross-repo consumers) and B-1's ratchet-vs-wall duplication that
  was deliberately not merged.
