### Learnings for future iterations

- **`--check` is the safe half of a regenerate command.** agora's evidence artifact regenerates with
  `node knowledge/src/evidence.ts` (writes) and verifies with the same command `--check` (re-runs the
  whole corpus, compares the content address, writes nothing). US-2's "no agora file is edited"
  constraint and US-1's "run the regenerate command" criterion are both satisfiable at once because
  of that seam. Reach for `--check` first in any cross-repo read.
- **agora TS modules run directly under node 22 with no build step.** `cd ~/Development/agora && node
  --input-type=module -e "import {...} from './knowledge/src/roundtrip.ts'"` works. That is what made
  the independent mutation probe cheap — do this rather than trusting an implementer's test names.
- **Perturb inside §3.1's hashed set, not outside it.** My first probe perturbed `confidence`, which
  is deliberately NOT in the hashed set, so a clean read would have been correct behaviour and the
  probe would have proved nothing. World / relation / argument / literal datatype are the fields that
  make rule 2 fire.
- **Read the merge stat before believing it.** agora `af5b7dd` touches 26 files, but 15 are an
  unrelated KFT 0.7.0 adoption carried on the same branch. Say which files are the gate.
