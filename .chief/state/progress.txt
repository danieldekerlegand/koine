## Codebase Patterns

- **Four version mirrors, not three.** A spec header bump must be echoed in `README.md`,
  `specs/README.md` (table AND the "Four sit there now — …" prose line ~195), `ECOSYSTEM.md` §2,
  and `CLAUDE.md`'s *Current state* prose. `check-doc-integrity.mjs` diffs only the three tables;
  the CLAUDE.md prose is unchecked, so edit it by hand and read it back.
- **Guards to run after any doc edit** (this is what `.chief/verify.sh` selects for `*.md`):
  `node scripts/check-doc-integrity.mjs`, `node scripts/check-doc-links.mjs --ratchet --base main`,
  `node scripts/check-tasklist-categories.mjs`. Add `check-schemas.mjs` if `schemas/` moved.
- **Patch-vs-minor in koine.** New *normative* text is not automatically a minor. House precedent
  (KCB 0.4.1 §2.3, KMI 0.3.2 §3.2) is: if nothing conformant stops conforming AND the next minor is
  already spoken for by a scheduled removal (KCB §7.3c forbids declaring and removing in one
  publication), it ships as a **patch** with that reasoning written into the changelog entry.
- **Changelog entries carry the reasoning, not just the delta** — what the clause fixes, the
  *Classification:* line justifying patch/minor, and a restatement of every open re-ratification
  gate (whether or not it moved). Match the surrounding entries' density.
