## Codebase Patterns
- **Anchor slugs: this repo's guard is NOT GitHub's.** `scripts/check-doc-integrity.mjs` `slugify()`
  strips `[^\w\s-]` then collapses a whitespace RUN to ONE hyphen. So `## Re-validation — KCS 0.3.0`
  is `#re-validation-kcs-030` (single hyphen), where GitHub would give `#re-validation--kcs-030`.
  Write the link, run the guard, fix — do not hand-derive it.
- **A "re-run the fold" gate is a two-axis read.** Walk the deltas against the spec's CURRENT text
  *and* against the CURRENT text of every plane it cites. Three of this repo's four 2026-09-03 walks
  (KMI MA-12, KCB/ADR-0014, KFT FT-W) broke on the second axis, not the first: the fold was fine, a
  neighbouring plane moved under it afterwards. Diff the plane's changelog since the fold's date.
- **A green KCS encoding is dated evidence.** It asserts the fold as of the run date against the
  spec version it pins. `kcs:producer-exhaust-finetune` ran 2026-08-24 pinning KFT 0.5.0 — it cannot
  see a break introduced by KMI 0.3.5 on 2026-08-26. Say which half of a walk is replay and which is
  hand-walk, per delta (the DR-7/DR-8 discipline).
